## Automation and human evidence boundaries

- P02 supplies isolated setup/minimum harness; P03/P04 permissions; P05/P06 durable round/finalization regressions; P07 independent report/workbook assertions.
- P08 adds focused React/Flutter component tests; P09 synthetic E2E, accessibility and reviewed visual checks. These do not establish real BLE or human usability.
- P10 adds guarded security scans and modest measured load/failure checks; they supplement E03–E12/E19 and do not establish crowd radio capacity.
- P11 wires implemented suites into commands and CI; hosted CI is unverified until actually run after the user's publication.
- P12 requires user/developer physical-phone help when unavailable to the agent; keep unrun device cases Blocked at execution. Formal participant UAT stays Deferred.
- P13 re-runs retained cases and reconciles evidence. No numeric coverage target substitutes for these outcomes.

P01 review gate: E01–E23 are mapped to expected results, methods and phases. Conditional policies are named rather than silently accepted. The next phase requires P01 approval and an explicit P02 start instruction.
